# ChatGPT MCP 터널 자동 복구

ChatGPT 경로의 `linkdeck_get_sleep_status`에서 `McpServerError: Session terminated`를 재현했습니다. 당시 앱의 휴대폰 포트는 정상이고 터널 프로세스와 MCP 수신 포트는 없었습니다. 기존 앱 재시작으로 동일 호출이 정상 반환됐습니다. 터널 프로세스를 종료하자 MCP 포트가 내려가고 호출이 타임아웃되며 자동으로 회복하지 않는 경로도 확인했습니다. 최초 프로세스 종료 이유는 보존된 로그가 없어 확정하지 못했습니다.

수정본은 기존 자동 연결 설정이 켜져 있을 때 터널 종료 후 1·2·4·8·16·30초 간격으로 재시도합니다. 간격 상한은 30초입니다. 수동 연결 해제와 앱 종료는 취소로 처리해 다시 연결하지 않습니다. 재시도와 정리 작업은 하나의 Task가 소유합니다. 키나 승인 범위는 변경하지 않습니다.

루나가 최종 코드를 검토하고 터널 테스트 10개를 통과했습니다. 이후 관련 Swift 테스트 28개와 앱 패키징·설치·서명 검증을 통과했습니다. 실제 설치본의 터널 자식 PID 96056을 종료한 후 PID 4323이 자동 생성되고 제어 서버 준비 상태까지 34.9초에 복구됐습니다. 앱 PID 95984는 유지됐으며, 동일 ChatGPT 연결의 `linkdeck_get_sleep_status`가 다시 정상 반환됐습니다. 복구 시간은 네트워크와 서비스 준비에 따라 달라집니다.

두 `.before` 파일은 이번 변경 전의 서비스와 테스트 소스입니다. 해당 원본으로 각 파일을 교체하고 맥 앱을 재빌드하면 이번 자동 재연결 변경을 되돌릴 수 있습니다. GitHub 커밋·푸시는 수행하지 않았습니다.
