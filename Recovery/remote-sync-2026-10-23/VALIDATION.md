# 동기화 최적화 검증

2026-10-23. 맥 /Applications/LinkDeck.app 및 연결된 실제 Android 휴대폰에 배포했습니다. 정식 APK는 release 빌드이며 디버그 검증 화면을 포함하지 않습니다.

## 구현

버튼·아이콘·사운드를 휴대폰 파일에 버전별로 저장합니다. 스킨은 기존 휴대폰 설정 저장소를 사용합니다. 연결 때 전체 리소스 버전과 최신 상태를 대조하고, 바뀐 리소스만 교체합니다. 삭제도 전체 리소스 교체에 반영합니다. 맥은 설정 변경이 없으면 아이콘 준비와 전체 JSON 생성을 반복하지 않습니다.

작업 시작·완료·오류·승인은 변경 경로에서 즉시 발행합니다. 3초 생존 신호는 별도이며 상태 발행을 지연시키지 않습니다. 휴대폰은 세션·순서 번호로 오래된 상태를 거부하고 완료·승인 알림을 중복 처리하지 않습니다. 연결 해제 시 작업 상태와 승인 표시를 지우고 연결 끊김을 표시합니다. 맥은 버튼 설정 버전과 실제 저장된 버튼·권한을 검증합니다.

같은 맥에서 실제 휴대폰 한 대를 연결하고 별도 측정 소켓 한 개를 열어 약 30초씩 측정했습니다. CPU는 LinkDeck 프로세스 누적 CPU 시간 차이를 경과 시간으로 나눈 단일 코어 기준입니다. 전송량은 측정 소켓으로 수신한 JSON 프레임 바이트이며 휴대폰을 포함한 전체 네트워크 합계가 아닙니다.
