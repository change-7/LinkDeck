# 작업 중 빠른 상태 확인

기존 두 서비스 소스는 *.swift.before에 보존했습니다. 복구 시 해당 원본으로 두 서비스를 교체한 뒤 맥 앱을 다시 빌드합니다. 다른 변경은 되돌리지 않습니다.

- 대기 중: 기존 파일 변경 알림 및 15초 보완 스캔 유지. 파일 감시를 사용할 수 없으면 기존 1초 대체 스캔 유지.
- 작업 중: 1초 보완 스캔 추가. 마지막 작업이 끝나면 제거.
- 승인 확인: 작업 또는 승인 대기가 있으면 0.5초, 없으면 기존 2초.
- 상태 이벤트 전송과 휴대폰 캐시는 기존 최적화 유지.

검증: 관련 Swift 테스트 43개 통과. 파일 변경 알림 없이 진행 중 작업 둘의 완료를 차례로 감지하고, 마지막 완료 후 빠른 스캔이 멈추는 실제 타이머 테스트 포함. 정식 맥 앱 패키징 및 설치 후 서명 검사 실시.
