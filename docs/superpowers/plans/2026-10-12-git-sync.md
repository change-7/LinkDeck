# Git Sync 실행 순서

사용자는 추가 계획 승인 없이 구현을 계속하도록 지시했다.

1. 별도 Git 설정/작업 모델, 비동기 프로세스, 감지 및 안전한 ff-only 엔진, 저장/중복 방지 구현. 임시 저장소 테스트.
2. FolderPairStore에 GitSyncStore를 연결하고 전후 연계, JSON 호환성, .git 보호 옵션 구현. MCP list/start/status/cancel 등록 및 기존 API 회귀 테스트.
3. 기존 Workspace에 Git 관리 화면과 FolderSync 연계 설정 추가. 등록/감지/선택/기록/취소 확인.
4. Swift 빌드/테스트와 실제 앱 MCP 임시 저장소 실행 검증. 변경을 검토하고 오류 수정. 실제 사용자 저장소는 건드리지 않는다.

관련 파일에 다른 작업의 변경이 있으므로 이를 보존하고 새 파일 중심으로 구현한다. 모든 실행 단계는 저장소 데이터 보존을 우선한다.
