# 여러 동작 묶기 승인 시안

- 승인 시안: `../Design/Workflows/multi-action-approved.png`
- 현재 상태: 시안 승인 완료, 기능 구현 전.
- 현재 앱 창 크기를 유지한다.
- 버튼 설정에서 여러 동작 묶기를 선택하면 4×4 버튼 아래의 빈 공간에 편집기를 표시한다.
- 동작 상자는 동작 종류·삭제 버튼과 설정값을 두 줄로 압축한다.
- 마지막 상자의 + 버튼으로 다음 동작을 추가한다.
- 한 줄에 최대 두 상자를 표시하고, 세 번째 상자부터 다음 줄로 이어진다.
- 연결선은 줄이 바뀌어도 실행 순서를 나타내며, 각 연결선에서 다음 동작 전 대기 시간을 설정한다.
- 이미지의 한 줄에 세 상자가 있는 배치는 승인 후 요청한 두 상자씩 줄바꿈 조건으로 변경한다.
